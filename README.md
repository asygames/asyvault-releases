# AsyVault Public Releases

This repository is the **public release-announcement channel** for the AsyVault browser extension.

- The source repository `asygames/asyvault` remains private.
- Users' encrypted vault backups are stored separately in **their own private GitHub repositories**.
- No source credentials, GitHub user tokens, master passwords, or unencrypted vault data belong here.
- Browser-native automatic updates require publication through the appropriate official browser extension store (Chrome Web Store, Opera Add-ons, Firefox AMO), or a separately configured supported self-hosted extension update channel.
- Published versions here are informational and may contain vetted signed release artifacts; a GitHub ZIP is not an automatically-installable update for Chrome on Windows or macOS.

**No security-audited stable release is available yet.** Do not import production credentials into early prototype builds.
